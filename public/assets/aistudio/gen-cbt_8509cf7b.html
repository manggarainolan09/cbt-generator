1. Akses dan konfigurasi

Sandi generator

  1. Pertama kali membuka file, buat sandi minimal 8 karakter dan ulangi sandi.
  2. Sandi diminta setiap kali generator dibuka. Tombol Kunci mengunci sesi aktif.
  3. Untuk mengganti sandi, pilih Ubah Sandi Akses di pengaturan.

Pengunci ini berlaku di browser lokal, bukan pengganti keamanan server.

Pengaturan ujian

Isi judul, sekolah, mata pelajaran, durasi, KKM, token, petunjuk, dan jadwal. Di bagian identitas, unggah logo dan ikon; pilih warna utama serta latar yang akan dipakai file CBT.

Atur pengacakan, tampilan nilai, batas perpindahan tab, dan kamera sesuai kebutuhan ujian.

2. Contoh TKA SD

Tombol Contoh TKA SD memuat 21 soal latihan orisinal bergambar (10 Bahasa Indonesia dan 11 Matematika), 30 akun VI-A sampai VI-C, konfigurasi 90 menit, KKM 70, dan token TKA2026. URL Apps Script contoh sudah terisi.

Login peserta

Username siswa01–siswa30, sandi 12345.

Contoh visual

Kebun resapan, kue pecahan, diagram batang, ukuran, dan geometri.

Perhatian

Memuat contoh akan mengganti konfigurasi, daftar peserta, dan bank soal yang sedang terbuka.

Acuan kompetensi: Kerangka Asesmen TKA SD Pusmendik. Bacaan dan ilustrasi dalam paket contoh dibuat orisinal.

3. Akun peserta

Mode Bebas

Peserta mengisi nama, kelas, dan asal sekolah sendiri.

Mode Login Akun

Peserta wajib memakai username dan password yang dibuat atau diimpor pengawas.

Tambah akun massal

Unggah Excel/CSV atau tempel baris dengan urutan username, password, nama, kelas.

username,password,nama,kelas
siswa01,12345,Ayu,VI-A
siswa02,12345,Bima,VI-A

Gunakan Cetak Kartu Login untuk mencetak empat kartu per halaman A4. Kartu berisi nama, kelas, username, dan password.

Tambahkan soal dari tab Bank Soal, pilih tipe, lalu isi pertanyaan dan kunci. Generator mendukung PG, PG kompleks, benar/salah, menjodohkan, isian, dan uraian. Unggah gambar, sisipkan rumus LaTeX, atur bobot, dan urutkan soal sesuai kebutuhan.

5. Penyimpanan draft

JSON lokal

Simpan JSON mengunduh salinan draft ke perangkat. Buka JSON memuatnya kembali dari file tersebut.

Draft online

Atur URL Apps Script, akun pengawas, dan Sync Token bila dipakai. Pilih Simpan Online, beri nama, lalu konfirmasi. Nama yang sama akan menimpa draft terdahulu. Pilih Buka Online untuk melihat daftar dan memuat draft.

Penyiapan pertama
  1. Salin kode GAS terbaru dari tab Integrasi Spreadsheet.
  2. Tempel dan jalankan setupDatabase.
  3. Deploy versi Web App terbaru. GAS membuat file spreadsheet CBT Draft Storage yang terpisah, dengan tab Draft CBT.
  4. Draft lama pada tab Draft CBT di spreadsheet CBT akan disalin ke file khusus ini saat pertama dipakai.

Draft berisi akun dan password siswa. Jaga spreadsheet khusus draft tetap privat. Batas ukuran draft online 1,5 MB.

6. Spreadsheet dan akun pengawas

  1. Masukkan URL Web App Apps Script di tab Integrasi Spreadsheet. Contoh TKA sudah berisi URL yang diberikan.
  2. Atur Sync Token bila digunakan. Akun pengawas awal adalah pengawas / pengawas; ganti password sebelum publikasi.
  3. Klik Salin Kode GAS, tempel di Apps Script yang terhubung ke spreadsheet, lalu jalankan setupDatabase.
  4. Deploy sebagai Web App (Execute as: Me; akses: Anyone), lalu gunakan URL berakhiran /exec.
  5. Setelah mengubah kode GAS, buat deployment versi baru. Tombol Uji Koneksi dan Kirim Data Uji membantu memeriksa koneksi.

7. Generate, bagikan, dan batasi pengerjaan ulang

  1. Hasilkan setidaknya satu soal dan pastikan konfigurasi wajib sudah diisi.
  2. Pilih Pratinjau Ujian untuk mencoba alur login dan tampilan ujian lengkap.
  3. Pilih Hasilkan Kode HTML, lalu unduh file HTML untuk dibagikan ke peserta.
  4. Untuk publikasi, gunakan Embed Google Sites atau panduan hosting Apps Script.
  5. Jika peserta sudah selesai, login berikutnya menampilkan peringatan dan nilai terakhir. Reset pengerjaan dari panel pengawas bila peserta memang perlu mengulang.

Pencegahan lintas perangkat dan nilai dari server memerlukan sync aktif serta deployment GAS terbaru. Tanpa server, riwayat hanya tersedia di browser/perangkat yang digunakan.
